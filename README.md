# Trilha de Atividades — DETRAN-PR

Este repositório é dedicado ao armazenamento, organização e versionamento das atividades desenvolvidas ao longo da **Trilha de Atividades do DETRAN-PR**.

O objetivo principal é registrar a evolução prática, soluções automatizadas, análises de dados e experimentos realizados durante o programa.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- 🐍 **Python** — Linguagem principal para desenvolvimento de scripts, automações e análise de dados.
- 🔀 **Git** — Controle de versão e gerenciamento de código.
- 🤖 **IA (Inteligência Artificial)** — Aplicação de técnicas e soluções baseadas em IA.
- 🧠 **LLM (Large Language Models)** — Utilização de modelos de linguagem para auxílio no desenvolvimento, revisão de código e engenharia de prompts.
- 🐼 **Pandas** — Manipulação, limpeza e análise estruturada de dados.
- 🌐 **Automação Web** — Criação de scripts para raspagem, navegação e tarefas automatizadas na web.
- 🔌 **API** — Integração, consumo e disponibilização de serviços e dados.
- 📊 **BI (Business Intelligence)** — Construção de visualizações, relatórios e dashboards para tomada de decisão.
